**Pre-existing live issue found (not changed; outside the approved rows).** The live `tll-acct-lists` v1.3 script calls `tllOwn()`, but `tllOwn` is declared only inside the first footer script's `__tllAcctStats` closure. Unless a hosted page script (probably tllacctmodcounts) defines `window.tllOwn`, `cardCounts()` and `wrapped()` throw a ReferenceError for any member with map data. The LOGGED number, the PAWED line, the Wrapped stats, and the new badges and "of 249" would then not appear. The mock defines `window.tllOwn` to stand in for that hosted script. Check this on the live page after publish (see below). The fix would be a one-line change, and it is a separate decision for Nancy.
