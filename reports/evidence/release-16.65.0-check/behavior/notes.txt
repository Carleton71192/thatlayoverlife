Behavior check of release 16.65.0 (core pin 0daa78b4, fix A2) on the real test site against real www (core 16.64.0, pin 6ec769bb).
Independent checker, read only: no Webflow tool calls, no publish. Checked 14 Nov 2026, 19:33 to 20:00 UTC.

Verdict: PASS WITH NOTES.

Method
- One plain GET per page per host (home, /stories, three stories). Story HTML on the two hosts differs only in the Last Published stamp and
  the core tag (pin and SRI); every other line is the same.
- Chromium (Playwright, chromium.launch() with no options), fresh context per load. Main documents and reloads went to the real hosts over
  the network (www.thatlayover.life and that-layover-life.webflow.io). Every non-GET aborted.
- Same-origin fetches made by scripts: served from the plain-GET copy of the same host. Webflow css and js: local caches (no misses).
  Webflow images, video, fonts: local caches; a miss was blocked (only the Croatia hero at 1440, two files, blocked on both hosts, so the
  hero box is there at 1440 but the photo is not drawn). jsDelivr: 16.65.0 core and two chunks fetched once and cached (the cached core
  matches the release SRI); everything else from earlier caches. Google fonts and third-party scripts cached after the first fetch.
  Memberstack served patched (no hiding when its aborted app POST fails), the same on both hosts, as in the 16.64.0 check.
- 390x844 at deviceScaleFactor 3 (mobile) and 1440x900. CLS = sum of every layout-shift entry with startTime up to 4 s.
  Hosts alternated each round. Stories: 10 fresh loads per page, width and host (120). Reload after scrolling to 2,500 px on the
  first story at 390: 5 per host. Home 390 and 1440, /stories 390: 3 per host, then 10 more /stories loads per host after an outlier.
- Files: table.md (per case), summary.json, loads.csv (one row per load, numbers only), harness/ (the scripts; in lib.cjs one class
  name string is split in two, otherwise as run).

  On all 65 test story loads style#tll-story-st3-early-v1 was added before first contentful paint and was gone by DOMContentLoaded;
  it was never present at the end. Both holds (data-tll-mg-wait-r and -d) were set on every test story load and none was left at the end.
  www never has the early style or holds (expected).
3 Finished page: byline avatar 44x44, radius 50%, image 44x44 on both hosts in every load. Hero, h1, byline, Receipts line and story body
  boxes: one final layout per case, the same on both hosts. Receipts line present on Balkans and Croatia (10 of 10 per width on both),
