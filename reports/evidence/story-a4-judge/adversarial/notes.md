# Fix A4, adversarial check (15 November 2026)

Verdict: FAIL, on one item. A4 (branch claude/fix-story-first-frame-a4-2026-11-14, head ea2cec2) is the best core I have measured on every normal load, on every parser stall and on streamed HTML, and it fixes the A3 weak spots it set out to fix (twelve countries, the stall after the hero, a throw at the top of the template script, now also a syntax error there). It still loses 0.14 to 0.15 when the site flag script fails on a Balkans-like story (www 0.017, A2 0.02), which is worse than both www and A2 by more than 0.1, the line set for this check. A2, which A4 would replace on the test site, does not have that weakness. A six-line change, tried in the lab below, takes it to 0.0195. One new weakness: a throw near the end of the template script now costs up to 0.157 (A3 0.013), under the 0.1 line but worth the same small fix. Nothing was published, no Webflow tool was called, nothing was merged.

## Method

2. **A throw near the end of the template script now costs up to 0.157 (A3 0.013). Note, by the rule.** Southern Africa 390: A4 0.157 on every load, www 0.060, A2 0.066, A3 0.013; Croatia 390: A4 0.064 (A3 0.007); Balkans 360: A4 0.049 (A3 0.009). ## Recommendation
Do not put ea2cec2 on the test site as it is. Add the two small changes tried as A4x (keep the stand-in box hidden when no flags came; release early on a template error only if the template has not added its page-parsed handler), rebuild, and recheck the flag-failure, template-failure and normal cells. Everything else in A4 is an improvement on A3 and on A2.
