## Appendix A: the current set and the method

The rule-level counts in sections 2, 3, 4, 6 and 7 and in the proposal (199 button rules, 89 card rules, 40 hero rows read into 12 treatments, 33 clamp() title sizes, 309 sub-12px rules in 70 files, 160 motion declarations, 265 duplicate bodies, 1,438 of 2,162 off-grid spacing values, 30 radii, 4,002 rules) come from one parse of the 185 files below, re-run on 1 November. The script is not in the repo (read-only pass); the method is: read each file as text, unescape `\'`, `\"` and `\n` so CSS inside JavaScript strings parses, match every `selector{declarations}` pair whose declarations start with a CSS property, keep the last line of the selector (after any `>` or `;` from surrounding code), and drop selectors that are at-rules, comments or code. Buttons are rules whose selector matches `btn|button|cta|-cta|.tll-st-b|data-tll-club|tlldir-contact|.tll-join|pill|.w-button|[data-tll-aw=btn|[data-tll-br=btn|-send]|submit]|chip` (hover, focus, active, pseudo-element and disabled rules excluded) and set padding, background, border, radius or a height. Cards: `card|.tll-*rail|shelf|tile|album|.h3-*(card|item|tile)|.tlldir-card|related|.tll-lib-` with a radius, shadow, aspect ratio, or fill plus padding. Heroes: `hero|cover|masthead|[data-tll-(aw|br|relay|club)=hero|section]|.tll-ph-|tll-lib-head|-head|.tll-top|landing` with a vh height, or fill plus padding, or an aspect ratio. Motion: every `transition:`, `animation:` and `@keyframes` in the file text, and `prefers-reduced-motion|tllReduced|reducedMotion|matchMedia(...reduced` as the guard test. Small type: every `font-size:Npx` and `font: ... Npx` under 12. Spacing: every `Npx` inside `padding`, `margin` and `gap`. Duplicate bodies: declaration lists of 40 characters or more, whitespace removed, seen in two files or under three selectors.
