That Layover Life bubbly icons, v2

Twenty-four chunky, colorful stamps for TLL pursuits and the map. Each one comes in two states: color for a pursuit that is done, and muted for one that is still open. Same drawings, same ink outline, fills swapped.

Grid 32 by 32, 2px ink outline with round caps and joins, flat fills from the TLL palette. Each cell shows color and muted at 48px, then the same pair at 32px.

On cream

#FDF9F3, the default for pages, cards, and the Paw Passport

On ink

#0A0B14, for dark sections, the map, and share cards. Color only, at 48px.

How to use

Two ways to place an icon

Paste the SVG inline, or reference the sprite. The colors are baked into each file, so nothing depends on CSS color. Never use an icon font.

<svg width="32" height="32" role="img" aria-label="Paw">
  <use href="/icons/sprite.svg#tll2-paw"/>
</svg>

<svg width="32" height="32" role="img" aria-label="Paw, not yet earned">
  <use href="/icons/sprite.svg#tll2-paw-muted"/>
</svg>

Color or muted

Use the color version (tll2-paw) once a pursuit is done or when the icon is the selected one. Use muted (tll2-paw-muted) for pursuits still on the list. Both sit on cream or white. On ink, use color only: the outline melts into the background and the icon reads as a sticker, which is the point. Small ink details (cookie chips, suitcase wheels, the bridge cable) go quiet there, and that is fine.

Sizes

Drawn for 32px. They hold up at 24px in chips and go as large as you like. Below 24px the faces turn to fuzz, so use the smaller v1 outline set there.

Where they go

  • Pursuit badges. Color once the pursuit is done, muted while it is open. 48px on the profile, 32px in lists.
  • Map pins. The icon sits inside the pin head at 24 to 32px. Use the color version only; muted reads as grey mud on the map.
  • Story card markers. One icon in the card corner names the pursuit, 32px. Keep it to one per card.
  • Filters. Icon plus label in a chip, 24px. The selected chip shows the color icon, the others show muted.
  • Empty states. One icon at 64 to 96px above the message. The muted version fits a page that has nothing in it yet.
  • Share cards. Color icons at 64px or larger, on cream or on ink. Give them room; two or three is plenty.
  • Paw Passport. The paw, map pin, and passport stamp at 48px as section marks, muted stamps for places still on the list.

Accessibility

Each file carries a title. When an icon sits next to a visible label, add aria-hidden="true" to the svg. When it stands alone, give it role="img" and an aria-label that says what it means, not what it looks like.

Style note

These are Japanese pop stickers, not line drawings. Every shape is inflated and rounded, the main feature is oversized, and a 2px ink outline holds it all together so the set reads as one hand. Fills are flat and come from the TLL palette only: rose, deep rose, teal, deep teal, amber, soft yellow, sky, mint, cream, and ink. Each icon uses two to four of them plus a small white shine. Eight icons carry a closed-eye face or a pair of blush dots (cookie, paw, suitcase, coffee cup, ferry, shot glass, mountain, and the cloud under the plane); the rest stay quiet so the set can sit next to Playfair Display headlines without turning the page into a sticker sheet. No gradients, no shadows, no text, no sharp corners.

At 64px and up

Files

48 SVGs (name.svg and name-muted.svg), sprite.svg with symbols tll2-name and tll2-name-muted, and this sheet. Everything is built from build.cjs; edit the drawings there, not in the output.

Compared with v1

v1 is the thin single-color stamp set on a 24 grid. v2 keeps the same 24 subjects and names, so the two sets can be swapped per surface. v2 is meant for places with room and color: badges, the passport, empty states, and share cards. v1 still works for tiny UI, like 16px list markers.
