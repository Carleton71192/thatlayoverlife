That Layover Life stamp icons

Twenty-four hand-drawn stamps for TLL pursuits and the map. Each one comes as an outline and an earned version: a solid stamp disc with the drawing pressed out of it. Phase C of the voice and visual refresh, for review before anything goes on the site.

Grid 24 by 24, 1.5px stroke, round caps and joins, color from currentColor. Each cell shows outline and earned at 48px, then the same pair at 24px.

Ink on cream

#0A0B14 on #FDF9F3, default for light pages

Teal on dark

#00C9C8 on #0A0B14, for dark sections and the map

Rose, active

#F0507A for the selected filter, current pursuit, or a freshly earned stamp

How to use

Two ways to place an icon

Paste the SVG inline, or reference the sprite. Both inherit color from CSS through currentColor. Never use an icon font.

<svg class="tll-icon" width="24" height="24" role="img" aria-label="Paw">
  <use href="/icons/sprite.svg#tll-paw"/>
</svg>

.tll-icon { color: #0A0B14; }            /* ink on light */
.dark .tll-icon { color: #00C9C8; }      /* teal on dark */
.tll-icon.is-active { color: #F0507A; }  /* rose, active */

Outline or earned

Use the outline (tll-paw) for a pursuit that is available or in progress. Swap to the earned stamp (tll-paw-earned) once it is done. Earned stamps read best at 32px and up; at 24px keep them for badges, not body text.

Where they go

  • Pursuit badges: outline while in progress, earned once complete.
  • Map pins: the stamp sits inside the pin head, sized 16 to 20px.
  • Story card markers: one stamp in the card corner names the pursuit.
  • Filters: stamp plus label in a chip; rose when selected.
  • Empty states: a single outline stamp at 48 to 64px above the message.
  • Share cards: earned stamps at 64px or larger, teal on dark or ink on cream.

Accessibility

Each file carries a title. When an icon sits next to a visible label, add aria-hidden="true" to the svg. When it stands alone, give it role="img" and an aria-label.
