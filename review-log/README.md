# Morning review logs

One file per day, `YYYY-MM-DD.md`, written by the scheduled task `tll-morning-review` (07:30 Copenhagen, approved in the beta log, B5.2, 20 October 2026). Each file holds the morning message, a ready-to-send note to the writer for every flag (Nancy sends them herself), and the run log. The task holds severity 1 to 3 by unpublishing the item; it never deletes, never edits a writer's words and never sends anything.
