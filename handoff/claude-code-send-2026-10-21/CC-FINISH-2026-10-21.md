## F1b · Per-story analytics (`?screen=account` → Contributions → Stats)
- **Tool:** Plausible Analytics (EU-hosted, cookie-free, no consent banner needed for it) on every page; or Fathom if Nancy prefers. Not GA4.
- **Events:** pageview (path = /stories/{slug}); `Read to end` (last paragraph enters viewport); engaged time (Plausible scroll + time); `Share` {channel}; `Save`; `Outbound` {url, affiliate:true/false}.
- **Who sees what:** a writer sees only stories where CMS author = their Memberstack id. Editor sees all. Fetch via a Cloudflare Worker that checks the Memberstack token, then calls the Plausible Stats API filtered by path. Cache 1 hour. API key never in the browser.
- **Shown:** Reads, Read to the end %, Avg time (of X min to read), Shares, Saves, Link clicks; reads-per-day bars; top 4 sources; top 5 reader countries. Period: 7 days / 30 days / All time. One plain-language nudge line from rules (read-through < 50% → first line; top source Instagram → share again; else keep title).
- **Privacy:** aggregates only. No reader names, no IPs, no city-level geo. Any number under 10 renders "Under 10". Add one line to the Privacy Policy.
- **Empty state:** "Numbers show up here once the first readers land." Never show zeros as a score. No ranking between writers, ever.
- The prototype's sample numbers are generated and labeled SAMPLE; build nothing from them.
