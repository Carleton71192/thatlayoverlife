The library, set like a magazine.

Every card below is a real story from the library, carrying the same details it has on the live /stories page. On a phone the grid is one plain column. Give it a desktop and the cards stop parking in tidy rows like rental cars and start behaving like a two-page spread.

Proposed grid

Below 600 pixels it is one column. At 600 the first of every five cards runs across both columns. At 900 and 1280 the grid turns into six and then twelve tracks, and each run of cards opens with a big card beside a tall partner. The pair swaps sides every other time, so the page never reads like wallpaper. Inside each band the titles share a row, so a two-word title and a twenty-word one hand over to footers that start on the same line.

Of the stories here, show their own hero photo, credited to the contributor and linked to the story. Every other card has a labeled slot where its hero would go.

    Today's grid

    The same cards in the layout that runs on /stories now. Every column is the same width and each card is exactly as tall as its title and excerpt make it, so the bottoms of a row rarely meet. A four-line title sits next to a one-liner like a carry-on that will not quite fit in the overhead bin.
