Home · 02 · Your travel dashboard

The dashboard map, animated.

The integration layer for an animation made in Fable: a player that takes a Lottie JSON, an SVG or a canvas export, a state machine that maps reader actions to its three segments, and a text version that says the same things. The Fable file was not attached to the brief, so the map below is a stand-in drawn in code on the same timeline. Drop the export into the config and the same triggers play it.

How the layer behaves

One controller owns the player. Triggers ask for a segment; the state machine decides whether it plays now, waits in the queue, or jumps straight to its end frame. Full notes, the drop-in steps and the events API are in the README beside this file.

States

StateWhenOn screen
idleBefore the chapter is within 600px of the screen. Nothing is loaded.The loading preview, still.
loadingThe player and export are loading, with an 8 second timeout.The preview, with a slow shimmer (none with reduced motion).
readyLoaded and resting on a frame.The animation, still.
playing:A playing:B playing:CA segment is playing. Map Unfold shows as A then C.Frames 0 to 45, 46 to 90, 91 to 150.
paused:offscreenOff screen or in a hidden tab. Playback and every frame loop are stopped.Nothing is drawn.
reduced-motionThe reader asked for less motion. Triggers jump to each segment's end frame.End frames only.
errorLoad failed or timed out.The still map, the description and the counts.

Triggers

TriggerPlaysIf something is already playing
view (35% on screen)A, onceNever repeats.
stamp:add (tick)BWaits in the one-slot queue. Many ticks replay B once more. The count and the spoken line update at once.
cta:enter (hover or focus)CWaits in the queue and takes the slot from B. Ignored while C itself is playing.
signup:successMap Unfold (A then C)Replaces whatever is playing and clears the queue.
pet:enter / pet:leavePaw Passport StampIndependent of the map timeline.

What the reader hears

  • "Stamp added. Three places on your map." when a trip is ticked, with the number worked out from the ticks.
  • "Route drawn through your three places." after C, or "Sample route drawn from Copenhagen to Sofia." with fewer than two stamps.
  • "Signed up. Your map is unfolding." then "Your map is ready." for Map Unfold.
  • "The animation did not load. The still map and this description stay in place." on error.
